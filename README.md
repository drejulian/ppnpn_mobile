# Documentation

## struktur folder :

## folder app
lib/app/http_client => semua terkait API (base url nya, dll)
lib/app/router => konfigurasi untuk routing

## folder common (semua fungsi/tampilan yang bisa di reusable)
lib/common/app => semua list asset (image, icon, dll)
lib/common/theme => semua konfigurasi untuk styling

## folder feature (semua yang terkait dengan ui dan data)

data => semua konfigurasi data api seperti model dan provider nya
presentation => semua yang berkaitan dengan ui seperti page dan widget
